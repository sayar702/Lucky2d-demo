LUCKY 2D Android Starter (DEMO ONLY)

ဤ ZIP သည် Android Studio အတွက် Source Project ဖြစ်ပြီး install လုပ်နိုင်သော APK မဟုတ်သေးပါ။

ပါဝင်သော prototype
- အနီ + ရွှေရောင် theme
- မြန်မာ / ထိုင်း language toggle
- Phone + password demo login UI
- Register demo UI
- သီးခြား Admin Login UI (username: admin; authentication မချိတ်ဆက်ရသေး)
- 00–99 demo number grid
- Demo record နှင့် demo slip screen

မပါဝင်သေးသောအရာများ
- Online Database / Firebase
- တကယ့် User registration နှင့် Admin approval
- 6 လုံး Access Code backend
- လုံခြုံသော Admin authentication
- QR image generation
- APK build လုပ်ပြီးသားဖိုင်

ဤ prototype သည် လောင်းကြေး၊ ငွေလက်ခံမှု၊ KPay ချိတ်ဆက်မှု၊ ငွေပေးချေမှု မပါဝင်ပါ။
Demo မှတ်တမ်းများသည် app လည်ပတ်နေစဉ် memory ထဲတွင်သာ ရှိပြီး app ပိတ်လျှင် ပျောက်နိုင်သည်။

Build လုပ်ရန်
1. Computer တွင် Android Studio ထည့်ပါ။
2. ZIP ကို Extract လုပ်ပါ။
3. Android Studio > Open ဖြင့် Lucky2D_Android_Starter folder ကိုဖွင့်ပါ။
4. Gradle Sync လုပ်ပါ (Android SDK 35 လိုအပ်သည်)။
5. Run ဖြင့် emulator သို့မဟုတ် USB debugging ဖွင့်ထားသော Android ဖုန်းတွင် စမ်းပါ။
6. APK ထုတ်ရန် Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုရွေးပါ။

Admin Password ကို source code ထဲတွင် hardcode မလုပ်ပါနှင့်။ Backend authentication ကို လုံခြုံစွာတပ်ဆင်ပြီးမှ အသုံးပြုပါ။
